# Website Memory

**VERIFIED** — `apps/web` is the frozen-architecture home for any web frontend ([ADR-0001](../../docs/decisions/ADR-0001-eta-system-target-architecture.md)). As of the last structural scan (`.claude/index/repository-index.json`) it is a stub (README only, no `src/`). Its own README describes it as an internal, auth-gated "Enterprise procurement UI" — a different purpose from a public marketing site.

**VERIFIED (2026-07-24)** — A live public website exists at `https://exiratlas.com`, confirmed by direct browser navigation (not just a screenshot). It is a simple static site (Home/About/Products/Industries/Contact), currently online, entirely separate from `apps/web` and from this repository — no ADR, no code, no deployment config for it exists anywhere in ETA-System. Its content diverges from the Blueprint vault's "Approved v1.0" website spec (`20-BRANDING/03-Website/*.md`, which describes a much larger React/Vite/Supabase/Lovable-hosted platform with customer/supplier portals) — treat the Blueprint spec as an aspirational/planned document, not a description of what's actually live. Do not assume identity between "the ETA website" as a business asset and `apps/web` as a repo package — they are confirmed different things, not just theoretically different.

**VERIFIED (2026-07-24)** — A second live system, `https://portal.exiratlas.com` ("ETA Operations Portal," Persian-language login page), was discovered linked from the marketing site's footer as "CRM Portal." Not logged into — only the login page was observed, no credentials attempted.

**VERIFIED (2026-07-24, source: direct user statement)** — The portal is **not** Microsoft Dynamics CRM, despite the footer calling it "CRM Portal." `portal.exiratlas.com` is a **Temporary Portal**, intended to eventually be **replaced by the ETA Platform** (this repo's target).

**SUPERSEDED same day by [ADR-0016](../../docs/decisions/ADR-0016-remove-dynamics-crm-eta-platform-extends-odoo.md)** — an earlier version of this note described a chain with Dynamics CRM 2016 On-Premise as an ongoing intermediate stage. That is now wrong: Dynamics is removed from the target architecture entirely (one-time legacy migration into Odoo, then retired — not an ongoing system). **Current target chain: Website → ETA Platform → Odoo ERP**, with the ETA Platform extending Odoo rather than replacing it. [ADR-0013](../../docs/decisions/ADR-0013-crm-target-microsoft-dynamics.md) (Dynamics as CRM target) is formally superseded. Full detail in [CR-008](../../docs/architecture/CONFLICT-REPORT.md#cr-008-live-public-website-and-operations-portal-exist-entirely-outside-this-repository--net-new-discovered-2026-07-24).

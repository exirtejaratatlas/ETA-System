# Prompt: Company Profile Design

**Use with:** `eta-companyprofile`, `eta-claudedesign-handoff`, `eta-branding`

```
Design a new/updated Company Profile document for ETA. Before drafting:
1. Locate any existing profile content via eta-knowledge-discovery.
2. Pull verified brand constraints via eta-branding — do not invent colors,
   fonts, or logo treatment from assumption.
3. Confirm the exact deliverable format (PDF, deck, one-pager) with the user.

This is a structured design deliverable — generate a Claude Design handoff
package via eta-claudedesign-handoff rather than producing final assets
directly in this session unless the user asked for that explicitly.
```

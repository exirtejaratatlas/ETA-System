# Prompt: Evidence Report

**Use with:** `eta-evidence`

```
Produce an evidence report for [claim/topic]. For every factual assertion,
provide: File Name + File ID/path, Folder Path (noting if reconstructed),
Heading, Section, a direct quoted excerpt (not a truncated snippet),
content hash (UNKNOWN if the source has none), Last Modified, Source Type,
and Confidence Level (VERIFIED only if you read it yourself this session;
otherwise PARTIALLY VERIFIED or UNKNOWN).

Do not round PARTIALLY VERIFIED or UNKNOWN up to VERIFIED for the sake of a
cleaner-looking report — an honest UNKNOWN is more useful than a false
VERIFIED.
```

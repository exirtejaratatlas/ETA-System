# Prompt: Claude CoWork Handoff

**Use with:** `eta-cowork-handoff`

```
Generate a Claude CoWork handoff package for [initiative]. Fill
.claude/handoffs/template-claude-cowork.md: context, requirements,
constraints, related ADRs, required documents, implementation status.

Explicitly restate the standing rules the initiative must respect (no
duplicate concepts, ADR required for structural change, production-safety
boundaries) — a collaborative, multi-person workspace doesn't get an
implicit exemption from them.
```
